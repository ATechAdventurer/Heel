# Heel 0.9.2 Beta · Build 17

**Install `Heel-v0.9.2-beta.apk` on both phones.** This is the unified app with Owner and Pet roles, for ARM64 Android phones running Android 8.0 or later.

## Install or upgrade

1. Download the APK from this release's Assets section and open it on your phone. Allow installation from your browser/file manager if Android asks.
2. Existing regular Heel beta users can install over their current app: the package ID and signing identity are unchanged. Saved pairing/settings and an explicitly saved relay address are retained. This does not replace the separate Dev Owner/Dev Pet apps.
3. New installs must set their own HTTPS relay address and use that host's private phone setup code. No hosted relay access is included. If an older install relied on the previous hardcoded address, set the address explicitly in Settings before reconnecting.
4. Use a pair invitation to link the phones, then follow Ready/Start. The Pet phone connects to the Bluetooth device.

[Relay setup instructions](https://github.com/sshado/Heel/tree/v0.9.2-beta/relay) · [Privacy and limitations](https://github.com/sshado/Heel/blob/v0.9.2-beta/docs/PRIVACY.md)

The source-code ZIP/tarball attached automatically by GitHub includes both `android/` and `relay/`. A separate relay-only ZIP is also included for self-hosters; extract it, enter the extracted directory, and follow `relay/README.md`. The installer generates a private code and configures HTTPS.

## Included in this beta

- Build 17's Ready-up softlock fix after Safe Word and reconnection. Delayed/duplicate status responses no longer prematurely clear the pending Ready state; rejection or timeout allows a retry.
- Smooth one/two-point vibration control, Hold, controller haptics, and recorded gestures in the Spellbook.
- Public first-run relay setup, without a hardcoded private server address.
- Bundled original-code and third-party license notices.

## Known issue

**Unexpected vibration after Safe Word followed by device disconnect/reconnect has been reported and remains unresolved.** This release addresses the readiness softlock, not that physical-device behavior. Test off-body with the physical power control within reach, and do not rely on the app as your only way to stop the device.

## Verification

- 108 Android tests and 41 relay tests passed locally; Android lint: zero errors.
- APK signature matches the existing regular Heel beta; Android package/version and 16 KB ZIP alignment verified.
- Native source is unchanged from the tested baseline; the existing native library was reused for this package. No new physical two-phone/Bluetooth testing was performed for this public packaging.
- The full Docker/HTTPS deployment has not yet been exercised end to end. GitHub Actions jobs could not start because GitHub reports an account billing lock; this is a locally built artifact.

This is a debug-signed hobby beta, not a Play Store release. `SHA256SUMS.txt` contains checksums for the APK and relay ZIP. Original code is BSD-3-Clause; dependencies and character artwork retain their separate rights.
